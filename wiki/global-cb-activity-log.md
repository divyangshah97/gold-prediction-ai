## How This Page Works

- Each entry covers **one country** and **one event** (purchase, sale, policy, announcement)
- Entries are added daily by the automated routine when new country-level gold news is found
- If a country already has a dedicated wiki page, this log links to it and the dedicated page is updated too
- If a country does **not** yet have a dedicated page, the event is captured here until enough data warrants one
